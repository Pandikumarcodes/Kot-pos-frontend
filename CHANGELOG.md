# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project follows semantic versioning once versioned releases begin.

## [Unreleased]

### Changed

- Standardized source structure and naming across routing, state, contexts,
  services, and feature modules.
- Improved shared form, dialog, loading, notification, and navigation
  accessibility.
- Corrected PWA asset paths and service-worker cache versioning.
- Added explicit not-found and unexpected-error experiences.

### Removed

- Removed unused components, hooks, service modules, Redux code, feature
  barrels, assets, debug logging, and unused packages.
